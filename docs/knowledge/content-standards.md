# Corporate Content Standards (コーポレート情報の編集基準)

Adopted 2026-10-16 from the founder's brief. Applies to every page, every language, and to any agent editing this site.
Facts come from `company-profile.md`; this file defines **how** they are presented.

## 1. Principles

1. **One master fact set, three edited versions.** Facts are fixed in `company-profile.md`. Each language (JA, EN, VI) is then *edited* for its readers, not translated word for word. Numbers, dates and names must be identical across languages.
2. **Japanese is written in Japanese corporate style.** Use the register and conventions of a Japanese 会社概要 (です・ます in prose, noun phrases in tables), not literal translations of Vietnamese or English sentences.
3. **Every figure has a definition, a scope and a date.** A number without "what is counted" and "as of when" is not published.
4. **Company, representative and message are separate.**
   - 会社概要 (Company profile): facts about the legal entity only, from its founding (October 2024).
   - 代表者紹介 (Representative profile): the founder's personal background (HEDSPI, Japan market since 2011, projects in other organisations).
   - 代表メッセージ (Message): the founder's beliefs and commitments.
   The founder's history (e.g. 2011) never appears as a company milestone.
5. **Cut what does not help a customer or partner decide.** No long, repetitive lists or generic statements ("cutting-edge", "best quality"). Prefer one concrete fact over three adjectives.
6. **Unverified = not published.** If a value is not confirmed, mark it "needs confirmation" in the knowledge base and leave it off the site. Never use an example or placeholder number.

## 2. Rules for specific items

| Item | Rule |
|---|---|
| Headcount | Publish an exact, dated number: 正社員12名（2026年10月現在） / 12 full-time employees (as of October 2026). **Do not publish ranges such as "10–50"**: they read like a job-board size bracket, not a company fact. Partner companies may be mentioned in prose without a number. |
| Founding / milestones | 会社概要 and 沿革 start at 2024年10月 設立. "2011" belongs only to 代表者紹介. |
| Project figures | Show simply as "30+ successful projects", no attribution note, no client names. |
| Market split 70 / 30 | Publish only with its definition: share **by number of projects**; Vietnam work is mainly DX. |
| AI engineer ratio | "70% of engineers": the denominator is engineers, not all staff. |
| Representative | Name and title as one table row (代表者: 創業者 兼 CEO　Nguyễn Thanh Bình). Full profile on the founder page. |
| Capital (資本金), banks, major clients | Only if confirmed and approved; otherwise omitted (not "TBD"). |
| Navigation | One entry per destination. The header CTA is the only contact entry; do not add a "Contact" nav item next to it. In-page CTAs link to the contact page (mailto stays a secondary text link only). |
| Technology names | Only with a project where the technology was used; never implies partnership or certification. |

## 3. 会社概要 table (order)

社名 / 商号（正式名称） / 設立 / 代表者 / 所在地 / 従業員数 / 事業内容 / 事業登録番号 / 電話 / メール
EN and VI use the same order with their own labels.

## 4. Checklist before publishing a content change

- [ ] Each new number has definition, scope and date, and matches `company-profile.md`.
- [ ] No founder history inside company sections, and vice versa.
- [ ] Japanese text reviewed for corporate register (not a literal translation).
- [ ] Same facts in JA, EN and VI.
- [ ] No ranges, placeholders or unverified claims.
