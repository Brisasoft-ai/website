# Baseline (before this revision), 2026-10-16

## Stack and deployment
- Static multilingual site (EN / JA / VI) generated by `build.mjs` (Node 18+, no runtime dependencies). Text in `src/i18n/*.json` (build fails on key mismatch), templates in `src/pages/*.html`, company facts in `src/company.json`.
- Hosting: Cloudflare Workers static assets (`wrangler.jsonc`), custom domains `brisasoft.net`, `www.brisasoft.net`, staging `stg.brisasoft.net`.
- CI/CD: `ci.yml` builds on PR; `deploy.yml` deploys staging on push to `main` and production on `v*` tag with an approval gate, with curl smoke tests.
- No forms, no backend, no analytics script, no cookies. Contact is by `mailto:`. Only first-party JS (`assets/main.js`: menu, language memory, year).
- Dev dependency: `wrangler`. `npm audit`: 0 vulnerabilities.

## Working tree at start
Uncommitted changes by the owner were already present and have been **kept**: privacy page, 404 page and `not_found_handling`, HSTS header, footer heading semantics, `sr` link labels, language summary label. They were not yet deployed (live `/en/privacy/` returned 404).

## Information architecture (before)
Home: banner, hero (decorative DNA/neural SVG), 4 numbers, "four areas of work", about + facts card, products, why (4 principles), 4-step process, Japan experience, vision, contact.
Other pages: About (company table, timeline starting with founder's 2011 background, founder name card, vision), Services, Products, BIS, AAB, Insights, Contact.

## Main problems found
1. **Company and founder history mixed.** Home stat "2011: working with the Japanese market since" shows the founder's date as a company figure; About timeline starts in 2011 inside the company milestones.
2. **No founder message** and no explanation of why the company exists. Founder block was a name and LinkedIn link only.
3. **Positioning generic** ("AI-native products and software solutions"); the AI-native way of working, the FDE mindset and the target markets (Japan, Vietnam) were not stated in the hero.
4. **Unsupported claim:** "earn BPMN workflow certification" (Oct 2025) with no certificate name, issuer or holder.
5. **Over-broad AI claims** in Services: "with source citations" and "so AI answers can be trusted" presented as general promises.
6. **Technologies** appear only inside prose; no indication of where each was used.
7. **Mobile bug:** the closed mobile menu sat off-screen and widened the page, causing sideways scrolling on every page below 860px (header `backdrop-filter` makes it the containing block for the "fixed" menu).
8. **Infra:** HTTP not redirected to HTTPS, no HSTS (pending deploy), no CSP.
