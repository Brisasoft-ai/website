# Japanese style guide (日本語表記・文体ガイド)

Audience: Japanese enterprise customers, SIer partners, technical decision-makers, candidates.
Japanese is edited as its own product, not translated from English or Vietnamese.

## Register
- 本文は「です・ます」調。表（会社概要・沿革）は体言止め・簡潔な名詞句。
- 主語は「当社」または「Brisasoft」。「私たち」は代表メッセージのみ。
- 過度な敬語・法律文書調は避ける。「〜させていただきます」は使わない。
- キャッチコピーは1か所（トップのヒーロー）のみ。同じ表現を他ページで繰り返さない。

## Formats
| Item | Format | Example |
|---|---|---|
| 年月 | YYYY年M月 | 2024年10月 |
| 時点 | （YYYY年M月現在） | 正社員12名（2026年10月現在） |
| 人数 | 数字＋名、雇用区分を明記 | 正社員12名 |
| 金額 | 万円、概算は「約」「相当」 | 約700万円相当 |
| 電話 | 国番号付き、ハイフン区切り | +84-927-997-699 |
| 括弧・コロン | 全角（）： | Brisasoft（ブランド名：Brisa） |
| 製品名 | 「」で囲む（本文中） | 自社AIプロダクト「BIS」「AAB」 |
| 代表者 | 役職＋全角スペース＋氏名 | 創業者 兼 CEO　Nguyễn Thanh Bình |
| 地名 | 大→小の順、原表記を括弧で併記 | ベトナム ハノイ市ロンビエン区…（Tầng 3, …） |

## Checklist for every JA change
1. 助詞・語尾の自然さ（声に出して読む）。
2. カタカナ語は一般的なIT用語に限る。
3. 箇条書きは文体をそろえる（体言止めか、です・ますのどちらか）。
4. 同じ事実を英語・ベトナム語と照合（数値・日付・雇用区分）。
5. 重要文書（会社概要・代表メッセージ）はネイティブ校正を推奨。
